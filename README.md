# BBS Studio — плагин для съёмки машинимы в Roblox Studio

Плагин по мотивам мода **BBS / Blockbuster** для Minecraft: записываете игрока, он превращается
в «актёра», который повторяет движения; актёрам можно менять скины прямо по ходу сцены, а камера
летает по ключевым кадрам со склейками между планами.

## Установка

1. Скачайте `dist/BBSStudio.rbxmx`.
2. Положите файл в папку плагинов Studio (в Studio: вкладка **Plugins → Plugins Folder**).
3. Перезапустите Studio — на вкладке Plugins появится кнопка **BBS Studio**.

Сборка из исходников: `rojo build default.project.json -o dist/BBSStudio.rbxmx`.

## Возможности

| Функция | Как работает |
|---|---|
| **Запись игрока** | В Play-тесте записываются позиция персонажа и все суставы (`Motor6D.Transform`) с заданной частотой кадров. Анимации ходьбы, прыжков, эмоций и инструментов попадают в запись. |
| **Многослойные дубли** | Во время записи уже снятые актёры и камера проигрываются вокруг вас, так что можно «играть в паре» с прошлыми дублями. Любого актёра можно перезаписать. |
| **Актёры** | Каждая запись становится актёром с вашим аватаром (берётся `HumanoidDescription`). Имя, время старта, вкл/выкл, дублирование, обрезка начала и конца по курсору. |
| **Скины (морфы)** | У актёра может быть сколько угодно скинов: любая модель из сцены (с теми же именами частей) или аватар любого игрока по нику/UserId. Скины меняются по таймлайну, актёра можно скрыть с нужного момента. Модель без Humanoid (машина, проп) просто двигается по записанной траектории. |
| **Камера и планы** | Ключи камеры из текущего вида Studio, FOV, переходы «Ровно / Плавно / Разгон / Торможение / **Склейка**». Склейка держит план до следующего ключа и мгновенно переключает его: так снимаются разные кадры. Траектория сплайном или прямыми. |
| **Таймлайн** | Линейка, дорожка камеры и по дорожке на каждого актёра. Клипы перетаскиваются мышью, отметки показывают смены скинов. |
| **Проигрыватель в игре** | Кнопка «Установить» во вкладке «Сцена» добавляет скрипт, который проигрывает сцену в запущенной игре по клавише (по умолчанию `P`): скрывает игрока, включает кинорамку, может стартовать автоматически или идти петлёй. Видео пишется любой записью экрана. |
| **Отмена** | Все изменения сцены поддерживают Ctrl+Z / Ctrl+Y. |

## Как снять сцену

1. Откройте окно **BBS Studio**.
2. Нажмите **Play (F5)**. В тесте откроется окно «BBS Studio — запись». Выберите «Новый актёр»,
   нажмите **● Записать**, после отсчёта сыграйте роль и нажмите **■ Стоп**.
   Горячая клавиша: *File → Customize Shortcuts → «BBS: запись / стоп»*.
3. Повторите для других ролей: прошлые дубли будут играть рядом с вами.
4. Остановите тест: записи появятся во вкладке «Актёры» с вашим аватаром.
5. Во вкладке «Актёры» добавьте скины и смены скинов, сдвиньте клипы на таймлайне.
6. Во вкладке «Камера» расставьте ключи и включите «Камера» в верхней панели, чтобы посмотреть
   сцену через камеру. Кнопка ▶ проигрывает её прямо в редакторе.
7. Во вкладке «Сцена» установите проигрыватель и снимайте фильм в игре.

## Где хранятся данные

- `ReplicatedStorage.BBS_Data`: актёры, записи (сжатый текст в `StringValue`), скины, ключи камеры
  и настройки проигрывателя. Сохраняется вместе с плейсом.
- `Workspace.BBS_Puppets`: «марионетки» для предпросмотра. Они пересоздаются из данных и **не
  сохраняются** в плейс (`Archivable = false`).
- Из теста запись передаётся в редактор через `PluginConnectionService`. Резервная копия лежит
  в настройках плагина, пока её не импортируют (вкладка «Запись» → «Сохранённые записи»).

## Ограничения

- Позы переносятся по именам частей, поэтому запись R15 корректно играет только на R15-скинах
  (то же для R6). Если у скина другой рост, ноги могут немного «парить» или уходить в пол.
- Записываются тело и позиция. Звук, чат и физика других объектов не записываются.
- Если в игре свой `StarterCharacter`, добавьте его актёру как скин через «+ Скин из выделенной модели».

## Структура

```
src/
  init.server.luau      точка входа: редактор → App, клиент теста → PlayApp
  Shared/               общий код (копируется в игру как BBS_Runtime)
    Codec               формат записи, интерполяция, обрезка, чанки
    CameraTrack         ключи камеры, сплайн, переходы и склейки
    Rig                 применение поз к любым моделям
    SceneData           хранение сцены в ReplicatedStorage.BBS_Data
    Playback            проигрывание актёров и камеры
    RuntimePlayer       проигрыватель внутри игры
  Plugin/
    App                 окно редактора: таймлайн, актёры, скины, камера, сцена
    PlayApp             окно записи в Play-тесте
    Recorder            запись персонажа
    Bridge              передача записей из теста в редактор
    Appearance          аватар игрока → скин
    Timeline, UI, History
```
