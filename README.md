# BBS Studio — плагин для съёмки машинимы в Roblox Studio

Плагин по мотивам мода **BBS / Blockbuster** для Minecraft: записываете игрока, он превращается
в «актёра», который повторяет движения; актёрам можно менять скины прямо по ходу сцены, а камера
летает по ключевым кадрам со склейками между планами.

## Установка

1. Скачайте `dist/BBSStudio.rbxmx`.
2. Положите файл в папку плагинов Studio (в Studio: вкладка **Plugins → Plugins Folder**).
3. Перезапустите Studio — на вкладке Plugins появится кнопка **BBS Studio**.

Сборка из исходников: `rojo build default.project.json -o dist/BBSStudio.rbxmx`.

## Возможности

| Функция | Как работает |
|---|---|
| **Запись игрока** | В Play-тесте записываются позиция персонажа, все суставы (и классические `Motor6D`, и `AnimationConstraint` новых аватаров Avatar Joint Upgrade) и состояние Humanoid (бег, прыжок, падение, лазание и т. д.). Анимации ходьбы, прыжков, эмоций и инструментов попадают в запись. |
| **Многослойные дубли** | Во время записи уже снятые актёры и камера проигрываются вокруг вас, так что можно «играть в паре» с прошлыми дублями. Любого актёра можно перезаписать. |
| **Актёры** | Каждая запись становится актёром с вашим аватаром (берётся `HumanoidDescription`). Имя, время старта, вкл/выкл, дублирование, обрезка начала и конца по курсору. |
| **Скины (морфы)** | У актёра может быть сколько угодно скинов: любая модель из сцены (с теми же именами частей) или аватар любого игрока по нику/UserId. Скины меняются по таймлайну, актёра можно скрыть с нужного момента. Модель без Humanoid (машина, проп) просто двигается по записанной траектории. |
| **Анимации скина** | Режим «анимации скина»: актёр идёт по записанной траектории и сам играет анимации своего скина (стоит / шаг / бег / прыжок / падение / лазание / сидит / плывёт), как стандартный скрипт Animate. Шаги подстраиваются под скорость. Анимации берутся из скина (его Animate), их можно заменить своими ID, взять у аватара любого игрока или вернуть стандартные Roblox. |
| **Позы по частям тела** | Вкладка «Анимация»: голова, грудь, таз, плечо и предплечье, бедро и голень (отдельно левые и правые), кисти, стопы и «всё тело». Поворот и сдвиг стрелками прямо в окне просмотра или числами. Ключ ставится автоматически, между ключами поза меняется плавно (переходы ровно / плавно / разгон / торможение / стоп-кадр). Позы накладываются поверх движения. Копирование и вставка позы. |
| **Дорожки (трекеры)** | Под выбранным актёром на таймлайне появляется дорожка у каждой части тела с ключами-ромбами (их можно перетаскивать) и дорожка действий. |
| **Действия** | Анимации в нужный момент: помахать, указать, танцы, смех, радость или любой ID. Скорость, петля, длительность. Действие плавно сменяет движение и уходит обратно. |
| **Камера и планы** | Ключи камеры из текущего вида Studio, FOV, переходы «Ровно / Плавно / Разгон / Торможение / **Склейка**». Склейка держит план до следующего ключа и мгновенно переключает его: так снимаются разные кадры. Траектория сплайном или прямыми. |
| **Таймлайн** | Линейка, дорожка камеры и по дорожке на каждого актёра. Клипы перетаскиваются мышью, отметки показывают смены скинов. |
| **Проигрыватель в игре** | Кнопка «Установить» во вкладке «Сцена» добавляет скрипт, который проигрывает сцену в запущенной игре по клавише (по умолчанию `P`): скрывает игрока, включает кинорамку, может стартовать автоматически или идти петлёй. Видео пишется любой записью экрана. |
| **Отмена** | Все изменения сцены поддерживают Ctrl+Z / Ctrl+Y. |

## Как снять сцену

1. Откройте окно **BBS Studio** (вкладка Plugins → BBS Studio).
2. Нажмите **Play (F5)**. Откроется окно «BBS Studio — запись», а сверху экрана игры появится панель
   **● Записать / ▶ Просмотр**.
3. Нажмите **● Записать**, после отсчёта сыграйте роль и нажмите **■ Стоп**.
   Дубль сразу становится актёром прямо в тесте, и **▶ Просмотр** его покажет.
4. Записывайте следующие роли: прошлые дубли играют рядом с вами.
5. Остановите тест (Shift+F5). Дубли станут актёрами в редакторе, а камера Studio наведётся на нового
   актёра. Кнопка **◎** у актёра наводит камеру на него, **Траектория** рисует его путь.
6. Во вкладке «Актёры» добавьте скины и смены скинов, сдвиньте клипы на таймлайне.
   Во вкладке «Анимация» выберите режим движения, поменяйте анимации скина, добавьте действия
   и настройте позы: выберите часть тела, поставьте курсор и поверните её стрелками в окне просмотра.
7. Во вкладке «Камера» расставьте ключи и включите «Камера» в верхней панели, чтобы посмотреть
   сцену через камеру. Кнопка ▶ проигрывает её прямо в редакторе.
8. Во вкладке «Сцена» установите проигрыватель и снимайте фильм в игре.

Горячие клавиши назначаются в *File → Customize Shortcuts*, поиск «BBS»: запись/стоп, просмотр,
воспроизведение/пауза, ключ камеры, в начало.

## Если что-то не работает

- Откройте **View → Output** и впишите `BBS` в фильтр. Плагин пишет о загрузке, каждом дубле
  (сколько кадров, отправлен ли в редактор, сохранён ли в резерв) и каждой ошибке.
- Тот же журнал есть во вкладке **«Сцена» → «Диагностика»**, там же видно число актёров и видимых марионеток.
- Если актёр есть, но его не видно, нажмите **◎** у актёра. Если камера наведена, а персонажа нет,
  значит, у актёра нет скина: добавьте его через «+ Скин из выделенной модели» или «+ Скин из аватара».

## Где хранятся данные

- `ReplicatedStorage.BBS_Data`: актёры, записи (сжатый текст в `StringValue`), скины (без скриптов),
  ключи камеры и настройки проигрывателя. Сохраняется вместе с плейсом.
- Марионетки для предпросмотра лежат в `Workspace.CurrentCamera.BBS_Puppets`. Они видны только в вашем
  окне Studio, не уходят соавторам в Team Create и не сохраняются в плейс.
- Скачанные анимации хранятся в `BBS_Data.Clips` в виде готовых данных: проигрыватель в игре
  использует их без загрузки. «Установить / Обновить» во вкладке «Сцена» докачивает недостающие.
- Позы марионеток плагин считает сам (все детали закреплены, суставы отключены). Поэтому просмотр
  работает и в режиме редактирования, где Roblox не применяет `Motor6D.Transform`.
- Из теста запись передаётся в редактор через `PluginConnectionService` (частями). Резервная копия лежит
  в настройках плагина и подтягивается автоматически, если основной канал не сработал.

## Ограничения

- Позы переносятся по именам частей, поэтому запись R15 корректно играет только на R15-скинах
  (то же для R6). Если у скина другой рост, ноги могут немного «парить» или уходить в пол.
- Записываются тело и позиция. Звук, чат и физика других объектов не записываются.
- Если в игре свой `StarterCharacter`, добавьте его актёру как скин через «+ Скин из выделенной модели».

## Структура

```
src/
  init.server.luau      точка входа: редактор → App, клиент теста → PlayApp
  Shared/               общий код (копируется в игру как BBS_Runtime)
    Codec               формат записи, интерполяция, обрезка, чанки
    CameraTrack         ключи камеры, сплайн, переходы и склейки
    Rig                 марионетки: своя кинематика по дереву суставов
    Log                 журнал (Output + вкладка «Диагностика»)
    Motion              итоговая поза: движение + действия + ключи поз
    Locomotion          анимации скина по траектории (стоит/шаг/бег/прыжок…)
    Clip, ClipLibrary   анимации Roblox в виде данных и их хранилище
    Anims, PoseTrack, Ease  наборы анимаций скинов, ключи поз, переходы
    SceneData           хранение сцены в ReplicatedStorage.BBS_Data
    Playback            проигрывание актёров и камеры
    RuntimePlayer       проигрыватель внутри игры
  Plugin/
    App                 окно редактора: таймлайн, актёры, скины, камера, сцена
    PlayApp             окно записи в Play-тесте
    Recorder            запись персонажа
    Bridge              передача записей из теста в редактор
    Appearance          аватар игрока → скин
    AnimTab, Gizmo      вкладка «Анимация» и стрелки в окне просмотра
    ClipLoader, BodyParts
    Timeline, UI, History, Version
```

## Тесты

Логику кодека, камеры, данных сцены, кинематики марионеток и передачи записей можно проверить без Studio
через [lune](https://github.com/lune-org/lune) (запускать из корня репозитория):

```
lune run tests/shared.luau
lune run tests/rig.luau
lune run tests/anim.luau
```
